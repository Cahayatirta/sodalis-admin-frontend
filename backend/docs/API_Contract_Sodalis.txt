================================================================================
1. GENERAL ARCHITECTURE & PROTOCOLS
================================================================================
- Protocol: HTTP / JSON RESTful API
- Port: 8000 (Local Windows & Production Standard)
- Default Character Set: UTF-8
- Authentication: JSON Web Token (JWT) Bearer Token in Request Header
- Row-Level Security: Managed securely via backend Supabase Service Role Key
- Document Uploads: Multipart Form-Data (Max File Size: 15MB, PDF/JPEG/PNG/WebP)
- Audit Trail: Immutable SHA-256 integrity hash on all compliance events

================================================================================
5. DATABASE SCHEMA FIELD MAPPING (EXISTING SUPABASE POSTGRESQL)
================================================================================

Table 1: users
- id (uuid, primary key)
- email (text)
- role (text: 'borrower' | 'investor')
- full_name (text)
- is_verified (boolean)
- created_at (timestamptz)
- phone (text)
- kyc_document_path (text, points to /uploads/kyc/{file})

Table 2: borrower_profiles
- id (uuid, primary key)
- user_id (uuid, foreign key -> users.id)
- full_name (text), email (text), phone (text)
- university (text), major (text), nim (text), semester (int4)
- gpa (numeric), sks (int4), attendance_rate (numeric)
- ai_trust_score (int4, 300 - 850)
- score_tier (text: 'Tier A' | 'Tier B' | 'Tier C')
- credit_limit (int8, IDR)

6. FRONTEND (REACT VITE + AXIOS) INTEGRATION SNIPPET
================================================================================
Create `src/api/client.js` in your React Vite application:

```javascript
import axios from 'axios';

export const apiClient = axios.create({
  baseURL: import.meta.env.VITE_API_URL || 'http://localhost:8000/api/v1',
  timeout: 15000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// Automatic JWT Bearer token attachment
apiClient.interceptors.request.use((config) => {
  const token = localStorage.getItem('sodalis_admin_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// Centralized error interceptor
apiClient.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('sodalis_admin_token');
      window.location.href = '/login';
    }
    return Promise.reject(error.response?.data || error);
  }
);
```
